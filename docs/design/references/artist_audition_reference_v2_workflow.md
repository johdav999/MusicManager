# Artist Audition Reference V2 Workflow

Reference image: `artist_audition_reference_v2.png`

Production corrections captured in this pass:

- Portrait is a large photorealistic artist image layered behind the vinyl record.
- Vinyl record asset uses a transparent center window so the portrait appears integrated instead of pasted above it.
- Stat meters are segmented gold blocks, not smooth stock progress bars.
- Contract controls use custom gold slider styling, not stock Unreal sliders.
- Icons use simplified high-resolution gold silhouettes so they remain readable at small HUD sizes.
- The panel has an internal vertical scroll region for content that exceeds the visible viewport height.
