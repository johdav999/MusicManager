## Intent

Create a production-quality AAA GUI reference for the main MusicManager gameplay screen. The reference preserves the 3D concert-stage playfield while adding a polished music-label management HUD using the project's dark vinyl, matte black, and warm gold design language.

## Implementation Target

Use this image as the visual target for the main gameplay HUD:

- Top status strip for date, label, cash, reputation, and time controls.
- Left artist/label summary rail with vinyl portrait motif and compact metrics.
- Right news feed with stacked readable news cards.
- Bottom command dock with premium icon buttons and space for additional commands.
- The active v2 reference uses a shorter bottom command dock with five command buttons: Audition, Market, Contracts, Studio, and Charts.
- Dark brushed surfaces, thin gold strokes, subtle vinyl grooves, restrained amber glow, and compact readable typography.
